# ParityDiff API Evidence

Use the ParityDiff MCP server to inspect captured public API contracts,
changes, SDK mappings, and release provenance. The plugin runs the pinned
public npm package as a local stdio server and requires Node.js 24 or later.

Ask Copilot to list a captured Sentry release, find its breaking changes,
and cite the source revision and operation before suggesting what to review.

Public evidence needs no ParityDiff account. Workspace reads and migration
drafts require a separate user-approved connection.

Setup and supported clients: https://paritydiff.com/mcp
